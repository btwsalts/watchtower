THE PLATFORM

One workspace. Multiple signals.

Watchtower is being developed as a connected defensive toolkit—not just a log viewer. Capabilities will arrive in tested, documented milestones.

Security event pipeline

Collect, validate, normalize, and query security events from systems and services.

Detection engineering

Build toward actionable rules, severity, alert lifecycle, and explainable detections.

Threat hunting

Search event timelines and connect activity into investigations with useful context.

Incident management

Organize findings, evidence, analyst notes, and response decisions in one workflow.

Endpoint & network visibility

Planned telemetry for Linux and Windows endpoints alongside network signals.

Threat intel & forensics

Build toward threat-intelligence enrichment, ATT&CK mapping, and investigation evidence.

BUILD IN PUBLIC

Built carefully. Milestone by milestone.

The public page is the starting point. The hosted multi-user service comes only after the backend is ready for it.

01 · CURRENT

Foundation

API, normalized events, persistence, tests, and local development setup.

02 · NEXT

Secure access

Authentication, tenant isolation, authorization, audit trail, and migrations.

03 · PLANNED

Analyst workspace

Dashboard, detections, alert lifecycle, and incident investigations.

04 · PLANNED

Telemetry & response

Agent identity, endpoint data, enrichment, and controlled response workflows.
